# CATSAY
- Like Cowsay - but with a cat

# Usage
- I already compiled the .sh script with shc
	* Just use that it's the easiest option
	* ./catsay Hello world
	* if that doesnt work you need to "chmod +x catsay"  
 
- Or you can compile it yourself using:
	* shc -f catsay.sh

- Or you can do whatever with the python script
